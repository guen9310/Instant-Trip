# StayLog

여행 경험 공유(SNS) 플랫폼 'StayLog'의 초기 학습 및 포트폴리오용 도메인 프로젝트입니다. 본 프로젝트에서는 핵심 기능 중 하나인 **실시간 채팅 서비스**를 우선적으로 구현하여, 기술적 역량을 검증하고 발전시키는 것을 목표로 합니다.

## 🎯 주요 목표 및 포커스

본 프로젝트는 다음의 기술적 역량 강화를 핵심 목표로 삼고 있습니다:

- **안정적인 타입 시스템 설계**: TypeScript를 적극 활용하여 예측 가능하고 유지보수가 용이한 코드를 작성합니다.
- **효율적인 상태 관리**: 
  - **Zustand**: 가볍고 직관적인 클라이언트 전역 상태 관리
  - **React Query**: 서버 상태 동기화, 캐싱 및 데이터 패칭 최적화
- **복잡한 폼 데이터 처리**: React Hook Form을 이용하여 채팅 입력, 프로필 설정 등 복잡한 폼의 데이터 처리 및 유효성 검증 성능을 최적화합니다.

## 🛠 기술 스택

- **Framework**: Next.js 16, React 19
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **State Management**: Zustand, React Query
- **Form Handling**: React Hook Form

## 🚀 시작하기

### 설치 및 실행

```bash
# 의존성 설치
pnpm install

# 개발 서버 실행
pnpm dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)에 접속하여 확인할 수 있습니다.
